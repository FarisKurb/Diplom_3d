# Визуализация кратчайшего пути в 3D-пространстве

Интерактивное 3D-приложение для вычисления и визуализации кратчайших путей вокруг полиэдральных препятствий. Разработано в рамках дипломной работы бакалавра.

## Возможности

- **4 алгоритма поиска пути** с переключением в реальном времени:
  - **Dijkstra** — граф видимости + сэмплирование граней + алгоритм Дейкстры
  - **A\*** — аналогичный пайплайн с эвристикой Евклидова расстояния
  - **Visibility Graph** — вершины меша и середины рёбер, поиск A\*
  - **Geodesic Approximation** — адаптивное подразделение рёбер с итеративным уточнением
- **Интерактивный 3D-просмотрщик** — вращение, панорамирование, масштабирование мышью
- **Поддержка нескольких мешей** — переключение между OBJ-моделями во время работы
- **Сглаживание пути** — жадное сокращение через проверку видимости
- **Отладочный оверлей** — визуализация исходного пути графа и узлов сэмплирования
- **HUD** — название алгоритма, длина пути, время вычисления, подсказки управления
- **Цветовая кодировка** — уникальный цвет пути для каждого алгоритма

## Запуск

```bash

```

## Архитектура

Приложение построено на **паттерне Стратегия** для поиска пути. Каждый алгоритм реализует абстрактный базовый класс `PathfindingStrategy` с единым интерфейсом `find_path()`, возвращающим датакласс `PathResult`.

```
PathfindingStrategy (ABC)
├── DijkstraStrategy         — Дейкстра
├── AStarStrategy            — A* с эвристикой
├── VisibilityGraphStrategy  — Граф видимости
└── GeodesicApproxStrategy   — Геодезическая аппроксимация
```

**Конвейер обработки:**

Меш → Сэмплирование граней/рёбер → Построение графа видимости → Поиск кратчайшего пути → Сглаживание → Рендеринг

## Алгоритмы

### Dijkstra
Классический алгоритм Дейкстры на графе видимости. Сэмплирует точки на гранях меша с помощью барицентрической сетки, строит граф видимости и находит кратчайший путь.

### A*
Аналогичный пайплайн, но использует A\* с эвристикой Евклидова расстояния до цели. Раскрывает меньше узлов при сохранении оптимальности.

### Visibility Graph
Узлы графа — вершины меша и середины рёбер. Не использует сэмплирование граней. Основан на теории о том, что кратчайший путь вокруг выпуклого многогранника проходит через его вершины.

### Geodesic Approximation
Трёхфазный алгоритм: (1) плотное подразделение рёбер + A\*, (2) итеративное уточнение вблизи найденного пути с удвоенной плотностью, (3) сглаживание. Сходится к истинному геодезическому пути.
