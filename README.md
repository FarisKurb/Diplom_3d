# Визуализация кратчайшего пути в 3D

Интерактивное 3D-приложение для вычисления и визуализации кратчайшего пути
между двумя точками при наличии одного препятствия в форме выпуклого
многогранника.

## Главное

- **Chen-Han Exact** - основной метод по умолчанию. Если отрезок между
  точками не пересекает внутренность препятствия, возвращается прямой путь.
  Если пересекает, строится выпуклая оболочка множества
  `vertices(P) + start + end`, а кратчайший путь ищется на ее поверхности
  оконным распространением Chen-Han по развёрнутым треугольным граням.
- **Dijkstra**, **A\***, **Visibility Graph** и **Geodesic Approximation**
  сохранены как дополнительные демонстрационные методы. Они строят
  дискретные графы, используют сэмплирование или поиск по характерным
  точкам, поэтому не заявляются как точное решение непрерывной задачи.
- Переключение алгоритмов работает клавишей **A**.
- HUD показывает активный алгоритм, длину пути, число точек и время расчета.
- Debug-режим поддерживает стратегии без графа: у Chen-Han Exact поле
  `graph` может быть `None`.

## Структура

```text
main.py                         # контроллер приложения и выбор стратегии
config.py                       # цвета, окно, камера, численные параметры
core/                           # Vector3, Ray, математические утилиты
geometry/                       # треугольники, пересечения, видимость
graph/                          # граф, Dijkstra, A*
mesh/                           # Mesh, OBJ-загрузчик, топология
pathfinding/
  strategy.py                   # PathfindingStrategy и PathResult
  chen_han_exact_strategy.py    # основной точный метод Chen-Han Exact
  dijkstra_strategy.py          # демонстрационный графовый метод
  astar_strategy.py             # демонстрационный графовый метод A*
  visibility_graph_strategy.py  # демонстрационный visibility graph
  geodesic_approx_strategy.py   # аппроксимация геодезического пути
render/                         # OpenGL-отрисовка меша, пути и HUD
interaction/                    # постановка точек мышью
assets/                         # OBJ-модели
tests/                          # модульные и интеграционные тесты
```

## Алгоритмы

### Chen-Han Exact

Стратегия `ChenHanExactStrategy` реализует основной сценарий для одного
выпуклого многогранного препятствия:

1. Проверяет, проходит ли прямой отрезок `start -> end` через внутренность
   препятствия.
2. Если прямой путь свободен, возвращает `[start, end]` без построения графа.
3. Если прямой путь невозможен, строит выпуклую оболочку из вершин
   препятствия и двух точек запроса.
4. На поверхности полученной триангулированной оболочки распространяет окна:
   каждое окно хранит интервал на ребре, образ псевдоисточника в текущей
   развёртке, расстояние до псевдоисточника, цепочку развёрнутых граней и
   predecessor-окно.
5. При переходе через ребро соседняя грань разворачивается в ту же плоскость,
   интервал окна проецируется на противоположные рёбра, а доминируемые окна
   на том же ребре отсекаются.
6. После достижения грани с конечной точкой путь восстанавливается обратным
   проходом по predecessor-окнам.

Путь может проходить через внутренности граней и не обязан идти по ребрам или
вершинам. Возвращаемые промежуточные точки - это пересечения геодезической
линии с ребрами между соседними развёрнутыми гранями.

### Дополнительные методы

- **Dijkstra** - строит граф видимости с barycentric-сэмплами граней и ищет
  кратчайший путь по дискретному графу.
- **A\*** - использует тот же тип дискретного графа, но с евклидовой
  эвристикой.
- **Visibility Graph** - строит граф по вершинам меша, серединам ребер и
  точкам запроса.
- **Geodesic Approximation** - уплотняет рёберные сэмплы и итеративно
  уточняет найденный графовый путь.

Эти методы полезны для сравнения и демонстрации, но они являются
дискретными/приближенными для непрерывной задачи.

## Запуск

```bash
python main.py
python main.py assets/Tetr.obj
python main.py --algorithm chenhan
python main.py --algorithm dijkstra
python main.py assets/cube.obj -a geodesic
```

Псевдонимы алгоритмов:
`chenhan`, `chen-han`, `chen_han`, `exact`, `dijkstra`, `astar`, `a*`,
`visgraph`, `visibility`, `geodesic`.

## Управление

| Клавиша / действие | Описание |
| --- | --- |
| Левый клик | Поставить начальную, затем конечную точку |
| Перетаскивание ЛКМ | Вращение камеры |
| Перетаскивание СКМ/ПКМ | Панорамирование камеры |
| Колесо мыши | Масштабирование |
| R | Сбросить точки и путь |
| S | Включить/выключить сглаживание |
| A | Переключить алгоритм |
| M | Переключить OBJ-меш |
| D | Включить/выключить debug-оверлей |
| H | Показать/скрыть подсказки |
| ESC / Q | Выход |
